## 🚀 Sobre Mim

Sou **Analista de Projetos e Negócios na MB Finance** e estudante de **Engenharia da Computação**, atuando na interseção entre **mercado financeiro, tecnologia e dados**.

Minha trajetória combina desenvolvimento de software com entendimento de negócio. Comecei trabalhando com desenvolvimento de aplicações web e mobile e, atualmente, atuo na construção e evolução de **soluções internas, automações, análises de dados e sistemas voltados ao mercado financeiro**.

Tenho experiência prática com **Python, SQL, React, React Native, JavaScript, C#, .NET e Java**, além de desenvolvimento de **APIs, modelagem de dados, automação de processos e Inteligência Artificial**.

- 💼 Atualmente: **Projetos & Negócios no mercado financeiro**
- 🤖 Interesse em: **IA, Automação, Dados e Fintech**
- 📊 Experiência com: **Python, SQL, análise de dados e automação**
- 💻 Desenvolvimento: **Web, Mobile, Back-End e APIs**
- 🎓 Engenharia da Computação
